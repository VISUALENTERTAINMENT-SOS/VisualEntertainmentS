01 — About me

Halo, aku Sandag!

Perkenalkan nama saya Anugrah Sandag, mahasiswa dari universitas klabat, berfakultas ilmu komputer dan berjurusan sistem informasi.

Website ini menggunakan 2 Bahasa pemograman utam yaitu CSS, dan JavaScript, dengan HTML sebagai kerangka dalam website. Saya juga menambahkan beberapa tools dalam website saya sebagai pendukung yaitu bootstrap dan VS Code. Ada juga AI yang saya gunakna yaitu ClaudeAI dengan website yang saya deploy dalam GitHub.

Website ini bertujuan untuk memperkenalkan portofolio diri saya sendiri mulai dari skill yang saya pelajari, perjalanan saya, dan pengalaman saya.
